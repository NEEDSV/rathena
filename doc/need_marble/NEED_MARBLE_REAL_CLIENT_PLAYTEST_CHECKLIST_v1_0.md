## 2. 접속 준비

1. **격리 서버:** Claude 세션이 이 브랜치의 격리 스택을 띄웁니다(`tests/need_marble/g2/bc_servers.ps1`, MariaDB 127.0.0.1:3327). 사람이 직접 띄울 때도 같은 스크립트와 절차를 씁니다. 서버는 127.0.0.1에만 바인딩되므로 **같은 PC에서만** 접속합니다. 원격 기기에서 하려면 포트를 외부에 열지 말고, 그 PC에 원격 데스크톱으로 접속해 플레이합니다.
2. **시험 클라 폴더:** 기존 KR 클라 폴더를 건드리지 않고 새 폴더를 만듭니다(약 5~6 GB 복사).
   - `tests\need_marble\client\make_mbqa_client.ps1 -Base <KR 클라 폴더> -Out E:\ttt\NEED_MBQA_CLIENT`
   - 스크립트가 하는 일: `need_marbl` 리소스를 복사하고, `clientinfo.xml`을 127.0.0.1:26901로 씁니다. 다른 접속 설정 파일은 비활성화합니다.
   - 다른 세션의 시험 클라(`E:\ttt\NEED_DQTEST_CLIENT` 등)나 라이브 클라는 쓰지 않습니다.
3. **계정**(격리 DB의 합성 계정. 비밀번호는 격리 스택의 `secrets.json`에만 있으며 문서·채팅에 쓰지 않습니다):
   - `mbqa_cpr`(일반, 캐릭터 2개: 계정 공용 확인용)
   - `mbqa_user`(일반)
   - `mbqa_gm`(GM 99: 정책 키·시계·주사위 지급 등 시험 조작)
4. **격리 DB 정책:**
   - 마스터 스위치 ON(키 1 = 1)
   - CP 실지급을 보려면 키 5 = 1. 격리 DB에서만 켜고, char writer 시험 빌드와 `need_marble_cp_grant`가 있어야 합니다.
   - 키 5 = 0이면 CP는 "지급 대기"로만 표시되는 것이 정상입니다.

## 4. UX 관찰 항목(숫자·배치는 이번에 바꾸지 않음)

- **칸 간 이동 속도와 정지:** 칸당 시간, 멈췄다 가는 느낌.
- **타일 시인성:** 크기, 텍스처(t0~t32)와 서버 좌표의 정렬 어긋남, 칸 번호·이름 판독.
- **위치 표시:** 현재 칸과 남은 걸음 안내, 도착 이벤트 문구 길이.
- **보상 확인 동선:** 대기 CP와 지급 CP를 구분할 수 있는지.
- **카메라·시야:** 보드 전체가 한 화면에 보이는지.

발견 사항은 다음 세 등급으로만 나눕니다. **심각**(진행 불가), **불편**(개선 권장), **연출·밸런스**(추후 조정).
