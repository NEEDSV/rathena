### 2.8 V20 CP 반영 단계 — 이번에는 요청하지 않음

APPLIED·UNCERTAIN 처리와 재접속 판정은 **제품 코드가 없다**. 실행할 대상이 없으므로 BLOCKED 로 둔다. 구현은 별도 설계·승인 대상이며, 구현되더라도 실제 `#CASHPOINTS` 쓰기는 이 문서 범위 밖이다. DECIDED 단계는 G2 에서 PASS.

## 5. 승인 문구 예시

> G2-A(V22 재실행·V18-C·V11)를 승인합니다. 포트·경로는 2절 후보, 2.0 게이트 통과 후 기동, 실행 시 시험 코드 작성(worktree tests/ 만) 포함, 종료 후 정리까지. 원본 3306·dqtest·원본 서버·원본 작업 트리 변경, CP 실지급, 푸시·병합은 금지.

G2-B·G2-C 는 따로 승인해 주시면 각각 진행한다. V18-C 의 "캡차 유발 처치" 처리와 전장 최소 표본·시간은 운영 결정이 필요하며, 시험은 관측값만 보고한다.
