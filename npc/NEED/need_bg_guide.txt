// 기존 전장(@전장대기) 대기열의 유효 대기자 수: 접속 중 + 같은 캐릭터 + 계정 중복 제외.
function	script	F_NEED_BGUX_RmQueueValid	{
	.@n = 0;
	for (.@i = 0; .@i < $@BG_RM_QUEUE_COUNT; .@i++) {
		.@aid = $@BG_RM_QUEUE_AID[.@i];
		.@cid = $@BG_RM_QUEUE_CID[.@i];
		if (.@aid <= 0 || .@cid <= 0)
			continue;
		if (!isloggedin(.@aid, .@cid))
			continue;
		for (.@j = 0; .@j < .@n; .@j++)
			if (.@seen[.@j] == .@aid) break;
		if (.@j < .@n)
			continue;
		.@seen[.@n] = .@aid;
		.@n++;
	}
	return .@n;
}

// 2:2 / 3:3 대기열의 유효 대기자. getarg(0) 2 = 2:2, 3 = 3:3.
// 반환 = 참가 확인 대상이 아닌 대기자 수, $@NBGUX_RC = 참가 확인 중(접속 중) 인원.
function	script	F_NEED_BGUX_ModeQueue	{
	.@mode = getarg(0);
	.@n = 0;
	.@rc = 0;
	.@qn = (.@mode == 3) ? $@NBG3_Q_N : $@NBG2_Q_N;
	for (.@i = 0; .@i < .@qn; .@i++) {
		.@aid = (.@mode == 3) ? $@NBG3_Q_AID[.@i] : $@NBG2_Q_AID[.@i];
		.@cid = (.@mode == 3) ? $@NBG3_Q_CID[.@i] : $@NBG2_Q_CID[.@i];
		if (.@aid <= 0 || .@cid <= 0)
			continue;
		if (!isloggedin(.@aid, .@cid))
			continue;
		for (.@j = 0; .@j < .@cnt; .@j++)
			if (.@seen[.@j] == .@aid) break;
		if (.@j < .@cnt)
			continue;
		.@seen[.@cnt] = .@aid;
		.@cnt++;
		.@in_rc = 0;
		if (.@mode == 3) {
			if ($@NBG3_RC) {
				for (.@k = 0; .@k < 6; .@k++)
					if ($@NBG3_RC_AID[.@k] == .@aid) .@in_rc = 1;
			}
		}
		else if ($@NBG2_RC) {
			for (.@k = 0; .@k < 4; .@k++)
				if ($@NBG2_RC_AID[.@k] == .@aid) .@in_rc = 1;
		}
		if (.@in_rc)
			.@rc++;
		else
			.@n++;
	}
	$@NBGUX_RC = .@rc;
	return .@n;
}

// 주간·랭킹 보상 정책 한 줄(현재 주차 기준). 2:2 정산 파일이 없으면 빈 문자열.

			"^FF0000Test period^000000: no weekly tier or ranking rewards for 2v2 / 3v3. First reward week starts ")
			+ callfunc("F_NEED_BG2P3_Date$", $@NBG2P3_WREW_FROM) + " KST";
	return needtr("주간 단계·랭킹 보상: 이번 주차부터 운영 규칙에 따라 집계됩니다(수령은 운영 스위치가 켜졌을 때).",
		"Weekly tier / ranking rewards: counted from this week under the live rules (claims open when the GM switch is on).");

// 메뉴의 "바로 신청": 원래 명령어 이벤트를 예약하고 대화창을 닫는다.
// 대화 중 doevent 는 엔진이 대기열에 넣었다가 이 스크립트가 끝난 뒤(0.1초) 실행한다.
function	script	F_NEED_BGUX_Apply	{
	.@ev$ = getarg(0);
	.@cmd$ = getarg(1);
	mes needtr("대화창을 닫으면 ^0055FF" + .@cmd$ + "^000000 명령어와 같은 절차로 신청합니다.",
		"When this window closes you apply exactly as with ^0055FF" + .@cmd$ + "^000000.");
	mes needtr("결과는 채팅창에 표시됩니다.", "The result is shown in the chat window.");
	close2;
	debugmes "[NEED_BGUX] APPLY aid=" + getcharid(3) + " cid=" + getcharid(0) + " event=" + .@ev$;
	doevent .@ev$;
	end;
}

// 기존 전장 bat_room 이동(마롤 전투 모집관과 같은 처리).
function	script	F_NEED_BGUX_GoBatRoom	{
	getmapxy(.@m$, .@x, .@y, BL_PC);
	if (.@m$ == "prontera") bat_return = 1;
	else if (.@m$ == "moc_ruins") bat_return = 2;
	else if (.@m$ == "aldebaran") bat_return = 3;
	else if (.@m$ == "geffen") bat_return = 4;
	else if (.@m$ == "payon") bat_return = 5;
	else if (.@m$ == "lighthalzen") bat_return = 6;
	else if (.@m$ == "rachel") bat_return = 7;
	else if (.@m$ == "morocc") bat_return = 8;
	else bat_return = 1;
	close2;
	warp "bat_room", 154, 150;
	end;
}

//------------------------------------------------------------
// 3:3 주간 순위 조회 (읽기 전용)
// 2:2 보상관의 주간 순위 화면(F_NEED_BG2P3_Npc case 6)과 같은 형식. 순위 계산은 3:3 원본 F_NEED_BG3P3_RankRows
// (mode 3, 완료 표식 need_bg2_match_done 이 있는 유효 경기만, 검토 보류 제외, 점수 > 승 > 승률 > 먼저 도달 > 경기 PK > 캐릭터 ID)
// 를 그대로 부른다. 지난 주 확정 상태·순위 보상권은 need_bg2_week / need_bg2_reward 를 SELECT 만 한다.
// 정산·확정·보상권 생성은 하지 않는다. "조회 순위"와 "보상 대상 순위"를 문구로 나눈다.
//------------------------------------------------------------
function	script	F_NEED_BGUX_Rank3	{
	.@n$ = getarg(0);
	mes .@n$;
	if (!$@NBG3P3_LOADED || !$@NBG2P3_LOADED) {
		mes needtr("3대3 점수 기능은 현재 운영하지 않습니다.", "3v3 points are not running now.");
		next;
		clear;
		return;
	}
	.@ws = callfunc("F_NEED_BG2P3_WeekStart", gettimetick(2));
	.@r = callfunc("F_NEED_BG3P3_RankRows", .@ws, 0, 1, 10);
	mes needtr("^0055FF3:3 룬 거점전 이번 주 순위^000000 (조회용 잠정 순위, 상위 10)", "^0055FF3v3 Rune Control this week^000000 (provisional, for reference, top 10)");
	mes "(" + callfunc("F_NEED_BG2P3_Date$", .@ws) + " ~ " + callfunc("F_NEED_BG2P3_Date$", .@ws + $@NBG3P3_WEEK) + " KST)";
	if (.@r <= 0)
		mes needtr("아직 기록이 없습니다.", "No records yet.");
	for (.@i = 0; .@i < .@r; .@i++)
		mes (.@i + 1) + ". " + $@NBG3P3_R_NAME$[.@i] + " - " + $@NBG3P3_R_PTS[.@i] + needtr("점 ", " pts ") + $@NBG3P3_R_W[.@i] + needtr("승 ", "W ") + $@NBG3P3_R_G[.@i]
			+ needtr("경기", " games") + ($@NBG3P3_R_G[.@i] < $@NBG3P3_MINGAMES ? needtr(" (후보 미달)", " (not eligible)") : "");
	if (.@ws < $@NBG2P3_WREW_FROM)
		mes needtr("^FF0000테스트 주간^000000: 이 순위는 조회용이며 3:3 랭킹 보상은 집계·지급하지 않습니다.", "^FF0000Test week^000000: this ranking is for reference only; no 3v3 ranking rewards are counted or paid.");
	else
		mes needtr("조회용 순위입니다. 보상 대상 순위는 다음 주 수요일 04:00(KST) 확정 때 정해집니다: 유효 경기 " + $@NBG3P3_MINGAMES + "회 이상, 그 주 참가 계정 " + $@NBG3P3_MINACC + "개 이상일 때 1~3위(계정당 1자리).",
			"This ranking is for reference. The reward ranking is settled next Wednesday 04:00 KST: " + $@NBG3P3_MINGAMES + "+ valid matches, ranks 1-3 (one per account) only when " + $@NBG3P3_MINACC + "+ accounts played that week.");
	next;
	mes .@n$;
	.@pw = .@ws - $@NBG3P3_WEEK;
	.@pst$ = "";
	query_sql "SELECT state FROM need_bg2_week WHERE `mode` = " + $@NBG3P3_MODE + " AND week_start = " + .@pw, .@pst$;
	mes needtr("지난 주(", "Last week (") + callfunc("F_NEED_BG2P3_Date$", .@pw) + "): "
		+ ((.@pw < $@NBG2P3_WREW_FROM) ? needtr("테스트 주간 - 순위 보상 없음", "test week - no ranking rewards") : (.@pst$ == "" ? needtr("확정 전", "not settled yet") : .@pst$));
	.@c = query_sql("SELECT r.rank_slot, COALESCE(c.name, '?'), r.amount, r.id, r.reward_kind FROM need_bg2_reward r LEFT JOIN `char` c ON c.char_id = r.char_id WHERE r.`mode` = " + $@NBG3P3_MODE
		+ " AND r.week_start = " + .@pw + " AND r.reward_kind IN ('RANK', 'RANKI') ORDER BY r.rank_slot", .@rs, .@rn$, .@ra, .@ri, .@rk$);
	for (.@i = 0; .@i < .@c; .@i++)
		mes .@rs[.@i] + needtr("위 ", ". ") + .@rn$[.@i] + " - " + callfunc("F_NEED_BG2P3_TicketText$", .@ri[.@i], .@rk$[.@i], .@ra[.@i]);
	mes needtr("^777777보상권 수령은 '2대2·3대3 보상관'에서 합니다.^000000", "^777777Claim reward tickets at the '2v2 / 3v3 Reward Officer'.^000000");
	next;
	clear;
	return;
}

//------------------------------------------------------------
// 지난 추석 이벤트 재료 정리 (7613 작은 찹쌀반죽 / 1001827 솔잎)
// 본인이 수량을 확인하고 고른 경우에만, 인벤토리에 있는 것만 회수한다. 창고·카트·길드 창고는 건드리지 않는다.
// 추석 제작/교환 NPC 가 내려가 쓸 곳이 없는 재료다. 보상은 없다. 두 아이템은 원래 버리기·판매도 막혀 있지 않다.
//------------------------------------------------------------
function	script	F_NEED_BGUX_EventMaterial	{
	.@n$ = getarg(0);
	setarray .@id[0], 7613, 1001827;
	mes .@n$;
	mes needtr("^0055FF지난 추석 이벤트 재료 정리^000000", "^0055FFClear old Chuseok event materials^000000");
	mes needtr("추석 송편 이벤트가 끝나 더 이상 쓸 곳이 없는 재료입니다.", "The Chuseok rice cake event is over, so these materials have no use any more.");
	.@total = 0;
	for (.@i = 0; .@i < 2; .@i++) {
		.@c[.@i] = countitem(.@id[.@i]);
		.@total += .@c[.@i];
		mes "- " + getitemname(.@id[.@i]) + " : " + .@c[.@i] + needtr("개", "");
	}
	mes needtr("^777777인벤토리만 확인합니다. 창고·카트에 있는 것은 인벤토리로 옮긴 뒤 다시 오세요.^000000", "^777777Only your inventory is checked. Move any in storage or your cart to the inventory first.^000000");
	if (.@total <= 0) {
		mes needtr("정리할 재료가 없습니다.", "You have nothing to clear.");
		next;
		clear;
		return;
	}
	mes needtr("^FF0000회수한 재료는 되돌릴 수 없고, 보상도 없습니다.^000000", "^FF0000Cleared materials cannot be restored and give no reward.^000000");
	if (select(needtr("모두 회수", "Clear them all") + ":" + needtr("취소", "Cancel")) != 1) {
		clear;
		return;
	}
	clear;
	mes .@n$;
	for (.@i = 0; .@i < 2; .@i++) {
		.@now = countitem(.@id[.@i]);	// 대화 중 수량이 바뀌었을 수 있으니 지금 수량으로 회수한다
		if (.@now > 0)
			delitem .@id[.@i], .@now;
		.@done[.@i] = .@now;
	}
	debugmes "[NEED_BGUX] EVENT_MAT_CLEAR aid=" + getcharid(3) + " cid=" + getcharid(0) + " 7613=" + .@done[0] + " 1001827=" + .@done[1];
	mes needtr("정리했습니다.", "Done.") + " " + getitemname(7613) + " " + .@done[0] + ", " + getitemname(1001827) + " " + .@done[1];
	next;
	clear;
	return;
}
